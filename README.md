# Eclipse Companion official APK releases

The latest signed Android installer is **Eclipse Companion 1.0.12** (version code 13).

- Update manifest: `latest.json`

The in-app updater reads `latest.json`, downloads the APK over HTTPS, checks its SHA-256, package ID, version code and signing certificate, then asks Android to open the system installer. Android always requires the user to confirm installation.
