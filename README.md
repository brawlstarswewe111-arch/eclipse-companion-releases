Version 1.1.1 delivers a major visual refresh, smoother transitions and interactions, reduced-motion support, two new complete themes (NASA Mission Control and Midnight Observatory), a curated home screen with a daily astronomy fact, and an interactive astrophotography target guide for the Moon, planets, stars/Milky Way and solar eclipses. Existing astronomy guidance, phone camera brand guides, observation tools and safety resources remain included.

The in-app updater checks latest.json, verifies the APK checksum, package, version and signing certificate, then guides the user through Android's installer. Android still requires the user to confirm installation.
