# Eclipse Companion official APK releases

The latest signed Android installer is **Eclipse Companion 1.0.15** (version code 16).

- [Download the latest APK](https://github.com/brawlstarswewe111-arch/eclipse-companion-releases/blob/main/Eclipse-Companion.apk)
- [Browse release history](https://github.com/brawlstarswewe111-arch/eclipse-companion-releases/releases)
- Update manifest: `latest.json`

The in-app updater checks the public GitHub manifest, downloads the APK, verifies its SHA-256, Android package ID, version code and signing certificate, then opens Android's system installer. Android asks the user to confirm installation. The 1.0.15 APK uses the same signing certificate as previous releases, so it can update an existing installation rather than requiring an uninstall.
